# Jacob Robinson - Product Engineer

Hey, I'm Jacob. I've spent the last 9+ years building product-facing platforms, internal tools, and the kind of software that ops teams and engineers actually depend on day-to-day.

Currently @**TLA** as their **Frontend SME**. Mostly frontend, often full-stack, increasingly building the machinery that builds the software.

## What I'm building

🚗 **[TrackAtlas](https://www.trackatlas.co.uk)** — UK track day aggregator with automated ingestion across 7 providers, MCP integration, and a predictive filtering system that stops you searching yourself into a dead end.

🏠 **[Property Ranker](https://property-ranker.vercel.app/)** — geospatial property comparison using UK Police API, Just Eat proximity, and Turf.js. **V2 is in progress**: a web app and browser extension with shared domain logic, geospatial enrichment, and property history. Also the guinea pig for my dark factory setup, because apparently buying a house wasn't enough of a project on its own.

🤖 **Dark factory** — building the pipeline while it builds Property Ranker V2. Claude Code and Codex agents picking up scoped tasks, working in isolated Git worktrees, running checks, reviewing changes, and recovering when things go wrong. The aim is less babysitting; getting there is currently a project of its own.

🎮 **Game Server Browser** — Next.js dashboard integrating Contentful, Pterodactyl, and GameDig with SWR polling.

🏎️ **AutoRaider** — browser extension that enhanced AutoTrader listings. RIP after markup changes.
